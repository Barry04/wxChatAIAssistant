# 约定

## 代码与数据
- [已验证] 请求数据使用 Pydantic 模型定义；新增 API 输入应优先在 `app/models.py` 建模，再由路由使用。
- [已验证] 结构化本地数据使用 JSON 或 JSONL，并统一通过 `app/storage.py` 的读写辅助函数操作。
- [已验证] JSON 文件写入采用临时文件替换；JSONL 采用追加写入。新增存储文件应沿用对应模式。
- [已验证] 关系类型固定为 `partner`、`friend`、`family`；新增类型需要同步模型、关系 YAML、默认数据和模板逻辑。
- [已验证] 导入文本按“对方消息后接本人回复”形成样本；不符合 `说话人: 内容` 格式的行会被忽略。

## 安全与隐私
- [已验证] 自动回复默认关闭且 dry-run；只处理白名单联系人，默认仅 L0 可自动发送。
- [已验证] 微信数据库读取不使用 OCR，私密密钥和派生配置只能保存在忽略提交的本地文件。
- [已验证] L3 高风险内容必须阻止直接草稿生成；L1/L2 必须保留用户确认提示。
- [已验证] 模型提示词不得允许编造事实、承诺、位置、行程或金钱决定。
- [已验证] 外部模型调用失败必须回退到演示候选，并将故障原因作为警告返回。

## 群聊与表达风格边界
- [已验证] 群聊默认仅在明确提及或配置为全部消息时触发自动化；未满足触发条件的消息只推进游标，不生成草稿。
- [已验证] 原始群聊消息可以写入本地原始记录；个人 Self Skill 蒸馏排除人数大于 10 或人数未知的群聊。
- [已验证] `girls-chat-style` 只迁移表达统计和风格类型，不迁移候选联系人的身份、称呼、事实、经历或聊天记忆。

## 测试约定

资格化评分：R=3、E=3、X=2、S=3、B=0，总分 11，决策为 `convention-only`。
- [已验证] 服务层测试直接导入 `app.services` 中的函数。
- [已验证] 场景、风险和导入解析属于低成本回归测试的优先对象。
- [已验证] 异步服务函数通过标准库 `asyncio.run` 包装为同步 pytest 用例，避免依赖额外异步插件。

## 运行与前端约定

资格化评分：R=3、E=3、X=2、S=3、B=0，总分 11，决策为 `convention-only`。
- [已验证] 后端统一由 `run.ps1` 从项目根目录启动。
- [已验证] 开发期前端通过 Vite 提供；后端 CORS 仅允许两个本地 5173 来源。
- [已验证] 只有在 `frontend/dist/assets` 存在时，后端才挂载构建产物。
- [已验证] React 工作台已接入核心 API；修改用户流程后需重新执行前端 lint、生产构建和浏览器验证。

## 不应升格为 Agent Skill 的知识
- 单个联系人 CRUD 路由。
- 单个 JSONL 字段或单个关系 YAML 的具体措辞。
- Vite 工作台的单个组件细节。
